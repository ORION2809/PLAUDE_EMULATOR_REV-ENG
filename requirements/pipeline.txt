# Track: pipeline/ (ASR/diarization stack under test)

# No packages were added to .venv for this track.  Everything used is
# already present: numpy, scipy, soundfile, av (PyAV 18 / libopus),
# pytest, pyannote.core (6.x, the stand-in tests build Annotations with it),
# pyannote.metrics, meeteval.  scikit-learn is present in the venv but
# deliberately NOT used (the model-free diarizer is numpy/scipy only).

# pinned in requirements/models.txt (2026-09-25; docs/pipeline.md section 11).
#

#                       + torch.  Both default pipelines are gated on Hugging Face.

#   speechbrain         RUN 2026-09-28/29 in a separate environment: speechbrain 1.1.1,
#                       torch 2.14.0, pinned in requirements/embedding.txt -- the
